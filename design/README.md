# 跑事 設計檔

給 Figma 用的設計素材。直接把 SVG 拖進 Figma 就是可編輯的圖層。

| 檔案 | 內容 |
|---|---|
| `支持跑事圓鈕.svg` | 手機版「支持跑事」咖啡圓鈕，放大 4 倍（256px，實際 64px）。圖層：底（黃色圓）、咖啡杯（向量線稿）、支持跑事（四個獨立文字圖層，已算好位置與旋轉）。 |

- 字體：Noto Sans TC Bold。
- 在 Figma 改完：選取群組 → 右鍵 → Copy as SVG 貼給 Claude，或匯出 SVG，Claude 會除以 4 套用到網站。
- 網站上實際的樣子以 `site/app.js` 裡的圓鈕為準；這裡的檔案是交換用的。
